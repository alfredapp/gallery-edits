## Usage

Test a website on multiple mobile device sizes via the `mobile` keyword.

![Keyword to launch a UI](images/keyword.png)

![UI showing a mobile website](images/ui.png)

* <kbd>⌘</kbd><kbd>P</kbd> Focus device picker.
* <kbd>⌘</kbd><kbd>↑</kbd> Select previous device.
* <kbd>⌘</kbd><kbd>↓</kbd> Select next device.
* <kbd>⌘</kbd><kbd>L</kbd> Focus URL field.
* <kbd>⌘</kbd><kbd>↩</kbd> Reload URL in field.

Alternatively, open a URL to test via the Universal Action.

![Universal Action to launch a test](images/ua.png)

Edit the list of devices or configure the window to open separately in the Workflow’s Configuration.
